# PK//PROTO — ピコ太郎版 ゲーム企画具体化ツール

考えた「核となる動詞」を、遊べる形と Unity の作り方まで落とす Web アプリです。
**生成AIのAPIは使いません。** プロンプトはすべて、スプレッドシートのDBから決定的に組み立てます。

- 静的サイト（ビルド不要）
- **データはスプレッドシート**（教員が直接編集できる）
- GitHub Pages に置くだけでサービスになる
- 1人15分で、DNAシート → ゲーム案 → 3プロンプト → Unity制作パッケージまで

---

## 1. 全体の形

```
[Google スプレッドシート]        ← 教員が編集する唯一の正
  27シート / パターン24件 / ツイスト20件
        │
        ├─ ① Apps Script（api モード）… シートは非公開のまま
        └─ ② 公開CSV（csv モード）  … サーバー不要・GitHubだけで完結
        ▼
[GitHub Pages の画面]  S0〜S10（AIなし・決定的）
        ▼
[学生の生成AI]  企画書／画面イメージ／Webゲームの3プロンプトを貼るだけ
```

**どちらのモードでも、画面のコードは同じものを使います。** `assets/js/config.js` の1行だけで切り替わります。

## 2. 3分で公開する（いちばん簡単：csv モード）

同梱の `csv/` フォルダに、DBの全シートがCSVで入っています。これだけで動きます。

```bash
git init
git add .
git commit -m "PK//PROTO"
git branch -M main
git remote add origin https://github.com/<account>/<repo>.git
git push -u origin main
```

GitHub の **Settings → Pages** → Source: `Deploy from a branch` / `main` / `/ (root)`。
数十秒で `https://<account>.github.io/<repo>/` が公開されます。

`assets/js/config.js` は最初からこうなっています。

```js
MODE: 'local'   // ← 同梱データで動く（授業は止まらない）
```

DBを効かせるときは、URLに `?db=csv` を付けるだけでも確認できます。

```
https://<account>.github.io/<repo>/?db=csv
```

常用するなら `config.js` の `MODE: 'csv'` に変えてコミットしてください。右上のチップが `DB CSV` に変われば成功です。

## 3. スプレッドシートをDBにする

### 3-1. 雛形を使う

`pikogen_db.xlsx` をGoogleドライブにアップロード → Googleスプレッドシートで開く。
27シート・ヘッダー・入力済みデータ・列幅・固定行がすべて入っています。

### 3-2. モード①：Apps Script（おすすめ・シート非公開）

1. スプレッドシートで **拡張機能 → Apps Script**
2. `tools/sheet_api.gs` の中身を貼り付けて保存
3. **デプロイ → 新しいデプロイ → ウェブアプリ**
   - 実行するユーザー：**自分**
   - アクセスできるユーザー：**全員**
4. 出た URL（`.../exec`）を `assets/js/config.js` の `API_URL` に貼り、`MODE: 'api'` にする
5. コミットして push

シートは非公開のままで構いません。生徒にURLを配るだけで、常に最新のDBが配信されます。

### 3-3. モード②：公開CSV（サーバーなし）

1. スプレッドシートで **ファイル → 共有 → ウェブに公開**
2. Apps Script の `exportCsv()` を実行すると、ドライブに `pikogen_csv` フォルダができ、27枚のCSVが出ます
3. そのCSVをリポジトリの `csv/` に上書きコミット（または公開URLを `CSV_BASE` に指定）
4. `MODE: 'csv'` にしてコミット

> CSVは「書き出した時点のスナップショット」です。シートを直したら再書き出しが必要。
> 常に最新を配りたいなら **モード①（API）** を選んでください。

## 4. シートの見方（27枚）

| 群 | シート | 役割 |
|---|---|---|
| 設定 | `設定` | スコアの重み・版番号・BPM |
| DNA | `マスタ_なぜ` / `マスタ_欲求` / `マスタ_認知` | 第3回のグループワークで選ぶ3点 |
| 入力 | `マスタ_対象` / `マスタ_IP` / `マスタ_感情` / `マスタ_動詞` / `マスタ_型` | 選択肢 |
| **案** | **`パターン`** | **1行＝1ゲーム案。文章はここを直す** |
| 案の子 | `パターン_IP` / `_UI` / `_素材` / `_音` / `_感情` / `_対象` | ID参照のみ |
| 実装 | `エンジン` / `エンジン_手引き` | シーン階層・手順 |
| 刺激 | `ツイスト` / `ツイスト_動詞` | 20種と、動詞からの対応 |
| 素材 | `素材` / `UI` / `SE` / `BGM` | 仮素材の作り方まで |
| 部品 | `Prefab` / `ジュース` | 機能名と演出 |
| 根拠 | `IP事実` | 提案書の「共感」で引用する事実と出典 |

### パターンを1件追加する（7ステップ）

1. `パターン` に1行追加（id は `P25`）。`active` は `TRUE`
2. `パターン_IP` に重みを5〜8行（0〜1）
3. `パターン_UI` に必須UIを4〜8行
4. `パターン_素材` `パターン_音` `パターン_感情` `パターン_対象` を各3〜6行
5. `マスタ_動詞` の該当動詞の `pat` を新しいIDに（または既存のまま）
6. `image_comp` `image_mood` `code_notes` を書く（ここがプロンプトの質を決める）
7. `validateDb()` を実行 → エラー0なら公開

### 直したら必ず実行

```js
validateDb()   // 参照切れ・空欄・手引き不足を一覧にする
```

これが無いと、3か月後に誰も直せないシートになります。

## 5. 画面の流れ

| STEP | 画面 | すること |
|---|---|---|
| 00 | はじめる | 説明（AIは企画を考えない） |
| 01 | **DNAシート** | なぜピコ太郎か（9択）／誰に（○○したい人）／認知ゴール |
| 02 | DNA 誰に | 遊ぶ相手 |
| 03 | DNA IPの価値 | 上限なし（選んだ数だけ重み） |
| 04 | DNA 感情 | 上限なし |
| 05 | DNA 動詞 | **1〜3個**（1個目が主役、2・3個目が仕掛け） |
| 06 | 挑戦の宣言 | 2D/3D、できること、挑戦したいこと、指導希望 |
| 07 | 作れる型 | 型で案を絞る |
| 08 | 確認 | 棚卸し |
| 09 | ゲーム案 | 1案＋「なぜこの案か」の重み表示＋刺激の1手 |
| 10 | プロンプト | 企画書／画面イメージ／Webゲーム |
| 11 | Unity制作パッケージ | 提案書（デザイン思考）／仕様／構成／素材／音／Prefab／刺激／演出／手引き／提出用 |

### 右上のチップ

| 表示 | 意味 |
|---|---|
| `LOCAL` | 同梱データで動作（DB未接続） |
| `DB CSV` / `DB API` | スプレッドシートから読み込み成功 |
| 赤い `LOCAL` | DBに繋がらなかったので同梱データで継続（授業は止まるが要修正） |

## 6. ファイル構成

```
index.html                  画面の骨格
assets/css/style.css        デザイン一式
assets/js/config.js         ★ DB接続設定（ここだけ書き換える）

assets/js/data.js           同梱データ（オフライン・予備）

assets/js/app.js            画面遷移・選択・コピー
csv/                        DBのCSV（csvモード用）
pikogen_db.xlsx             スプレッドシート雛形（27シート）
tools/sheet_api.gs          Apps Script（DB API・検証・CSV書き出し）
tools/build_xlsx.py         db.json → xlsx / csv を作り直す
tools/dump_db.js            data.js → db.json
```

### 同梱データを更新したとき

```bash
node tools/dump_db.js          # data.js → db.json
python3 tools/build_xlsx.py    # db.json → pikogen_db.xlsx と tools/csv/
cp tools/csv/*.csv csv/        # csvモード用に反映
```

## 7. ピコ太郎の扱い（重要）

公式素材は使いません。画像生成プロンプトも、実在の人物の顔・公式ロゴ・実在ブランドを禁止しています。

- 固定する記号：**黄色 / 黒のヒョウ柄 / 角刈りパンチ / 鼻にちょいがけの黒縁眼鏡 / 口髭**
- 音：BPM128・4つ打ちのループを **Web Audio で合成**（音源ファイルなし・著作権リスクなし）
- セリフ：歌詞は使わず、**Pen / Apple / Pineapple などの単語と掛け声のみ**
- 生成した画像を公開する場合は、授業の範囲に留めてください
